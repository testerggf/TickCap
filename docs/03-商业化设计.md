# 03 · 商业化设计

## 1. 商业模式总纲

**Freemium 订阅制**。记录功能永久免费且不设恶心限制（记录是数据资产的来源，卡记录 = 自断命脉）；**AI 与"时间资产增值服务"收费**（复盘深度、报告体系、同步与安全）。

定价哲学：免费版是一个**完整可用的时间轴日记**，会员版是**多一个 AI 人生教练**。用户为"更懂我的复盘"和"我的数据更安全"付费，而不是为解锁基础功能付费。

## 2. 免费 vs 会员（TickCap Pro）

| 能力 | 免费版 | Pro |
|------|--------|-----|
| 滴答记录 / 时间轴 / 封存 | ✅ 无限制 | ✅ |
| 预置标签 | ✅ 全部 | ✅ |
| 自定义标签 | 5 个 | 无限 |
| AI 日复盘 | **每周 3 次**（默认模板） | 每天不限次，全部模板 + 自定义模板 + AI 人设 |
| AI 周报 / 月报 | 每月体验 1 次周报 | ✅ 全部，含一键工作周报 |
| 年度报告 | ✅ 基础版（人人可分享——增长引擎不设墙） | ✅ 完整版 + 高级海报样式 |
| 语音滴答 | — | ✅ |
| 洞察统计 | 近 7 天 | 全部历史 + 自定义追踪目标 |
| 那年今日 | ✅ | ✅ |
| 云同步 / 多端 | 单设备本地 | ✅ 多端同步（端到端加密可选） |
| 数据导出 | ✅ 永久免费（隐私承诺的一部分） | ✅ |
| AI 对话检索（P2） | — | ✅ |

**免费额度的设计逻辑**：每周 3 次日复盘，刚好够用户在"最想复盘的日子"尝到甜头，又必然在某个充实的周四晚上撞到"本周次数已用完"——此时展示的不是冷冰冰的付费墙，而是"今天记录了 14 颗胶囊，是本月最充实的一天，让 AI 帮你好好复盘一下？"

## 3. 定价（国内市场）

| 方案 | 定价 | 折合 |
|------|------|------|
| 月度 | ¥15/月 | 锚点，主要用来衬托年度的划算 |
| 年度（主推） | ¥98/年 | ¥8.2/月，上线期早鸟 ¥68/年 |
| 终身 | ¥298（限时/限量发售） | 冷启动期回笼现金 + 制造稀缺话题 |

- 新用户 7 天 Pro 全功能试用，**试用从第一次封存时开始计算**（确保试用期覆盖的是有记录可复盘的 7 天，而非下载后空跑）。
- AI 成本护栏：日复盘单次成本可控（结构化输入 + 中档模型即可有好效果）；周/月/年报告用高档模型。Pro 定价对 AI 成本的覆盖率需按 DAU 复盘率持续监控，超额重度用户（如自动化刷 API）设公平使用上限。
- 海外版（远期）：$4.99/月、$29.99/年，AI 功能对海外用户成本相同但付费力更强，出海是利润率放大器。

## 4. 付费触发点设计（何时、如何让用户想付费）

原则：**在用户情绪价值最高的瞬间出现，而不是在用户被拦住的瞬间出现。**

1. **免费复盘次数用尽时**（上文所述话术，转化主力）
2. **首次生成周报体验后**：展示完整周报 → "每周日晚自动为你生成，还能一键转成工作周报" —— 对画像 A 是直接的时间置换（付 ¥8/月，省每周 40 分钟写周报）
3. **记录满 30 天时**：展示"你已积累 247 颗胶囊"的资产盘点 → 引出多端同步与加密备份（损失厌恶：数据越多越怕丢）
4. **年度报告发布季（12 月）**：基础版人人可分享（拉新），完整版与高级海报是 Pro 权益——每年一次的付费高峰
5. **试用到期前 1 天**：给一份"你的试用 7 天 AI 为你总结了什么"的回顾，用已经获得的价值说话

反面清单（永远不做）：开屏广告、信息流广告、记录条数限制、导出收费、删除数据挽留弹窗。记录类产品的信任一旦破产，永不回头。

## 5. 增长设计

### 5.1 分享即增长（产品内生传播）

- **年度报告海报**（最强引擎，对标网易云年度歌单）：故事感 + 数据奇观（"你今年最早的一次起床是 5:40"），海报自带下载引导
- **周报卡片**：一张"我的一周时间去哪了"配色精美的分享图，效率人群朋友圈的社交货币
- **高光胶囊卡片**：单颗胶囊生成金句卡片分享（类 flomo/Readwise 卡片）
- **连续封存成就**：第 30/100/365 天生成里程碑卡片
- 所有分享图带二维码 + 邀请码：被邀请者与邀请者各得 14 天 Pro

### 5.2 冷启动策略

1. **种子人群**：效率工具社区（少数派、即刻·效率工具箱、小红书手账/自律 tag、V2EX）——画像 A/C 的聚集地，发"我用 2 次点击记录了一整天"的演示视频与产品故事
2. **内容营销**："摸鱼也值得被记录"这类反内卷叙事天然有传播性；"AI 帮我写周报"是效率区流量密码
3. **构建公开产品日志（build in public）**：本产品自身就是记录工具，用 TickCap 记录开发 TickCap 的每一天，把时间轴截图发出来——产品即广告
4. 上线期终身会员限量发售制造紧迫感，回笼首批现金流验证付费意愿

### 5.3 留存设计（比拉新更重要）

- 晚间封存提醒（可关，文案轮换、有人味，拒绝"您今日尚未打卡"式机器人话术）
- 那年今日推送（记录满 30 天后解锁，天然的召回钩子）
- streak 连续封存 + 里程碑彩蛋
- 每周日晚"周报已生成"推送——一周一次的必看时刻
- 流失召回：离开 7 天的用户收到的不是"快回来"，而是"你上次记录停在 3 月 14 日 22:41——『终于把方案交了』。后来呢？"

## 6. 财务健康度粗算（第一年目标）

| 指标 | 保守目标 |
|------|----------|
| 累计下载 | 100,000 |
| 次周留存 | 35% |
| 付费转化率（活跃用户→Pro） | 5% |
| 付费用户 | ~3,000（年费为主） |
| 年收入 | ~¥25–30 万 |
| 主要成本 | AI 调用（严控在收入 25% 内）、服务器、开发者账号 |

第一年目标不是赚钱，是验证两件事：**封存率**（价值闭环成立吗）和**免费→付费转化**（AI 复盘值得付钱吗）。两者成立，这个模式可以规模化；出海后 ARPU 翻 3 倍。
