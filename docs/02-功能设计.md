# 02 · 功能设计（PRD）

> 优先级标注：**P0** = MVP 必须有；**P1** = 第二阶段；**P2** = 远期。

## 1. 信息架构

```
TickCap
├── 今日（首页）—— 竖向时间轴 + 底部滴答记录栏
├── 档案馆 —— 日历视图 / 已封存的每一天 / 那年今日
├── 报告 —— 日复盘 / 周报 / 月报 / 年度报告
├── 洞察 —— 时间分配统计、趋势图表
└── 我的 —— 标签管理、模板管理、AI 设置、数据导出、会员
```

底部导航四个入口：**今日 · 档案馆 · 报告 · 我的**（洞察并入报告页作为 Tab）。首页永远是"今日时间轴"，打开 App 即可记录——这是 3 秒原则的第一道保障。

## 2. 核心功能一：滴答记录（P0）

记录一次 = 生成一颗**时间胶囊（Capsule）**。胶囊的数据结构：

| 字段 | 说明 | 必填 |
|------|------|------|
| 时间段 | 开始时刻 ~ 结束时刻 | 是（自动推断） |
| 标签 | 大类标签（可多选，主标签决定胶囊颜色） | 是 |
| 一句话概括 | 简短描述，如"写 Q3 方案" | 否 |
| 详细记录 | 展开的长文本，支持轻量 Markdown、图片（P1） | 否 |
| 心情 | 5 档 emoji 心情（😫😕😐🙂🤩） | 否 |
| 高光标记 | 手动星标"这一刻值得记住" | 否 |

### 2.1 记录流程（核心交互，必须极致顺滑）

**入口**：首页底部常驻"滴答栏"——一排高频标签 + 一个输入框 + 滴答按钮。

**最快路径（2 步）**：打开 App → 点一个标签 → 完成。时间段自动推断，胶囊立即挂上时间轴。

**标准路径（3 步）**：点标签 → 输入一句话概括 → 滴答。

**完整路径**：点标签 → 概括 → 展开详情框写长内容 / 选心情 / 调整时间 → 滴答。

**时间自动推断规则（本产品最重要的隐形设计）**：
- 新胶囊的**开始时刻 = 上一颗胶囊的结束时刻**，**结束时刻 = 现在**。用户按时间顺序记录时完全无需碰时间选择器，流水账自动无缝衔接。
- 时间可手动微调：拖动时间轴上的胶囊边缘，或点击时间文字修改（15 分钟为默认步进，可设为 5 分钟）。
- 当天第一颗胶囊：开始时刻默认为用户设置的"**默认起床时间**"（默认 7:00）或"现在往前 1 小时"，取近者，并引导用户确认——通常这颗就是「起床」。
- 凌晨记录的归属：另有一个独立设置"**日界**"（默认凌晨 4:00），凌晨 1 点记的「夜宵」会归到昨天的时间轴——符合"昨晚"的人类心智。两个设置的精确规则见 [07 §2](07-详细技术设计.md)。

**补记与插入**：长按时间轴的空白区段 → 直接为该区段补一颗胶囊。空白区段在时间轴上以浅色虚线呈现，并显示"这 2 小时你在做什么？"的轻提示——不施压，但给记录完整主义者一个钩子。

### 2.2 标签体系

**预置大类（每个自带 emoji 和颜色）**：
💼 工作 · 📖 学习 · 🍜 吃饭 · 🚇 通勤 · 🏃 运动 · 😴 睡眠 · 🛁 生活杂务 · 🎮 娱乐 · 🗣 社交 · 🧘 休息 · 🌫 摸鱼 · 💭 发呆 / 思考 · ☀️ 起床 · 🌙 睡觉

设计要点：
- **摸鱼和发呆是一等公民**。这是产品态度（诚实的镜子），也是传播梗——"这个 App 居然让我理直气壮地记录摸鱼"。
- 标签支持二级：如 工作·会议、工作·写代码。滴答栏展示一级标签，长按展开二级（P1）。
- 自定义标签：自选 emoji + 颜色 + 归属大类。免费版自定义上限 5 个，会员无限。
- 滴答栏的标签按"当前时段使用频率"智能排序：早上 8 点通勤标签靠前，晚上 10 点睡觉标签靠前（P1，MVP 先按总使用频率）。

### 2.3 辅助输入方式

- **语音滴答（P1，会员功能）**：长按滴答按钮说一句话，"刚才一小时在开产品评审会"，AI 自动解析出时间段、标签、概括。这是移动场景的杀手锏。
- **快捷指令 / 桌面小组件（P1）**：iOS 锁屏小组件、灵动岛计时；Android 桌面 1x1 快捷标签。
- **正在进行模式（P1）**：滴答时选"开始"而非"完成"，胶囊处于进行中状态（灵动岛/通知栏可见），结束时再点一下——适合精确计时爱好者，但永远不强制。

### 2.4 提醒系统（P0 基础版 / P1 智能版）

记录习惯的最大敌人是"忘了记"。提醒系统是把用户从心流里轻轻捞出来 3 秒的艺术——**捞得太勤是骚扰，捞得太少是失职**。

**基础配置（P0）**：
- 间隔提醒：用户自选间隔（30 分钟 / 1 小时 / 2 小时 / 自定义）
- 生效时段：如 8:00–22:00 之外绝不打扰；工作日与周末可分开配置
- 一键暂停：今天不想被提醒（请假/度假模式），到期自动恢复

**智能节流（P0，防骚扰是提醒系统的生命线）**：
- 距上次记录不足间隔的 60%，本次提醒自动跳过——刚记完不烦你
- 检测到用户刚主动打开过 App，跳过下一次提醒
- 连续 3 次提醒未响应，自动降频一档并在 App 内告知（"最近好像有点忙，提醒已放缓，随时可调回"）——**宁可少提醒，不可被关通知**，通知权限一旦被用户关掉几乎不可逆
- 日历检测到"忙碌/会议中"则顺延到日程结束（P1）

**提醒文案**：轮换、有人味、带上下文——"距上一颗胶囊已经 1 小时 24 分了，这段时间在忙什么？"，拒绝"您有一条记录待完成"式机器人话术。

**通知即记录（P1，真正的 0 秒记录）**：
- iOS 长按通知 / Android 展开通知，直接出现 4 个高频标签按钮 + "写一句"快捷回复框——**不打开 App 就完成一颗胶囊**
- 通知上的标签按当前时段的使用习惯动态排列（早高峰是通勤，午间是吃饭）
- 点通知主体进 App 时自动聚焦滴答栏，可立即手写或长按语音
- ⚠️ 各端提醒能力差异大（Web Push 在 iOS 上需先"添加到主屏幕"；小程序靠订阅消息；完整体验在 App 端），服务端统一调度、按端选最优通道——详见 [05-技术架构 §7](05-技术架构.md)

**通知权限申请策略**：onboarding 绝不上来就要权限（授权率会很难看）。在用户完成第一次封存、刚体验完 AI 复盘的高光时刻再请求："想在明天帮你继续记录吗？"——用已获得的价值换授权。

### 2.5 快速回填（P1）

总有一整天忘了记的时候。快速回填是"晚上 90 秒补完一天"的批量补记模式：进入空白的当日时间轴，底部是标签盘，点选标签 → 在时间轴上划一段区间 → 下一个。像切蛋糕一样把一天切完，随后照常封存复盘。**断一天不该毁掉一个习惯**——回填让"漏记的一天"从挫败感变成一个 90 秒的小游戏。

### 2.6 自动胶囊：无感记录（P1 日历 / P2 健康数据）

记录成本的终极答案是"很多胶囊根本不用你记"：
- **日历导入（P1）**：读取系统日历，日程自动生成**草稿胶囊**（虚线灰色态）挂在时间轴上，用户点一下确认即转正，也可忽略或修改——开完会打开 App，那颗"周会"胶囊已经在等你了
- **健康数据（P2）**：睡眠时长（起床/入睡胶囊自动草稿）、锻炼记录（运动胶囊草稿）来自 HealthKit / Google Fit
- **铁律**：自动数据永远只是"草稿"，经用户确认才上时间轴。这条时间轴必须始终是"我记录的人生"，而不是"机器监控的日志"——主权感是记录意愿的心理基础

## 3. 核心功能二：时间轴（P0）

**竖向时间轴是产品的脸面，必须美。**

### 3.1 视觉与结构

- 从上到下按时间排列，左侧是细的时间刻度线（标注整点），胶囊挂在刻度线右侧。
- 每颗胶囊是一张圆角卡片：`[emoji] 一句话概括 · 时长`，卡片左边缘一条主标签色的色条，与刻度线的连接点是一个小圆点（胶囊的"挂钩"）。
- **胶囊高度与时长弱相关**：设置最小/最大高度区间内按时长缩放——一天扫下来，视觉上直接感知到"大块时间去哪了"，但短记录也不会小到看不见。
- 有详细记录的胶囊右下角显示一个小角标，点击展开全文。
- 有心情的胶囊，挂钩圆点替换为心情 emoji——一眼扫过一天的情绪起伏。
- 空白区段：浅灰虚线段，长按补记。
- 当前时刻：一条呼吸动效的"现在"横线，随时间下移——强化"时间正在流动"的感知。

### 3.2 交互

- 单击胶囊：展开详情（查看/编辑全部字段）。
- 长按拖动胶囊边缘：调整起止时间，相邻胶囊智能吸附。
- 左滑：删除（可撤销）；右滑：标记高光 ⭐。
- 顶部日期栏左右滑动切换日期，点日期弹出月历。

### 3.3 封存仪式（P0，情感设计的核心）

每晚（默认 21:30，可自定义）推送一条温和提醒："今天的时间轴还差最后一步"。用户进入今日页，点击底部的**「封存今日」**：

1. 时间轴快速回放动画（从早到晚滚动一遍，2 秒）
2. 展示 AI 日复盘（见第 4 节），用户可编辑、可补写"今日一句话"
3. 确认封存 → 整条时间轴收拢成一颗**大胶囊**，带动画沉入档案馆
4. 展示连续封存天数（streak），第 7/30/100 天有彩蛋动画

封存后仍可解封编辑（不搞惩罚），但 streak 记录以首次封存为准。**封存是本产品的习惯锚点**——它给一天画上句号的仪式感，是用户第二天继续记录的心理动力。

## 4. 核心功能三：AI 复盘与报告体系（P0 = 日复盘，P1 = 周/月，P2 = 年报）

### 4.1 日复盘（P0）

触发：封存时自动生成；也可在报告页手动生成/重新生成。

AI 的输入是**结构化数据**（这是复盘质量远超竞品的根本）：当日全部胶囊的时间段、时长、标签、概括、详细记录、心情，加上用户的历史画像摘要（P1）。

**默认模板输出**：
1. **一日纵览**：一段 80 字以内的叙事总结，写得像朋友帮你回顾，而不是冷冰冰的清单
2. **时间账单**：各大类时长与占比（图表由前端渲染，AI 负责一句点评）
3. **高光时刻**：AI 从详细记录里挑出 1–3 条值得铭记/深想的内容（用户手动星标的必选）
4. **情绪线**：如果记录了心情，点出情绪拐点及其前后发生的事
5. **明日一问**：一个基于今天内容的开放式问题，如"你提到和老张聊跳槽有点触动，触动你的到底是什么？"——引导用户写一笔真实的思考

**模板系统**：
- 预置模板：标准复盘 / KPT（Keep-Problem-Try）/ 感恩日记 / 效率教练（严格版，会指出时间浪费）/ 极简（只要三行）
- 自定义模板（会员）：用户用自然语言描述想要的复盘结构和口吻，保存为模板
- **AI 口吻人设**可选：温柔陪伴型 / 客观分析型 / 严厉教练型——同样的数据，不同的灵魂

**AI 复盘的三条产品红线**：
1. 生成结果永远可编辑，用户的修改要保留
2. 每份复盘底部固定有"补一笔"输入框，鼓励用户手写一句——用户原话是数据资产中最珍贵的部分
3. AI 不做道德评判，"效率教练"的严格也只针对用户自己设定的目标

### 4.2 周报 / 月报（P1）

- 输入：本周期全部日复盘 + 胶囊统计数据
- 周报结构：本周叙事总结 / 时间分配对比上周 / 本周高光 Top3 / 被忽视的事（如"运动连续 3 周为 0"）/ 下周一个建议
- **一键转工作周报（画像 A 的杀手锏）**：单独的模板，只取工作类胶囊，输出可直接提交的工作周报草稿
- 月报增加：本月关键词云、习惯趋势（睡眠时间线、专注时长趋势）

### 4.3 年度报告（P2，但要早做——它是最强增长引擎）

对标网易云音乐/Spotify 年度报告的传播力：
- 今年共记录 N 颗胶囊，记录了 N 天
- 最早的一次起床及那天的故事 / 最晚的一次睡觉
- 年度关键词、时间分配全景、心情最好的一个月
- 12 个月各选一颗高光胶囊，串成"你的一年"
- 生成精美长图海报，一键分享（海报只含用户选择公开的内容）

### 4.4 AI 对话式检索（P2）

在报告页与自己的数据对话："我上次见老王是什么时候？""过去三个月我平均几点睡？""把我所有关于跳槽的思考整理给我"。记录积累越多，这个功能越接近"第二大脑"，是长期留存的护城河。

## 5. 核心功能四：档案馆与回忆（P1）

- **日历视图（回看的主入口）**：每天一个小色块拼图（按当日主要标签配色），已封存的日子有标记，一屏看到一个月的"人生底色"。**点任意日期进入当日详情页：完整时间轴 + 当日 AI 复盘 + 手写感想 + 心情曲线**，支持继续编辑与补记——过去的每一天都随时可回、可改、可补
- **那年今日**：每天推送一次"一年前/一个月前的今天你在做什么"，点进去看当天时间轴——记录满一个月后，这是留存利器
- **高光馆**：所有星标胶囊的瀑布流，你人生的精选集
- **搜索**：全文搜索所有胶囊与复盘

---

## 6. 洞察统计（P1）

- 时间分配：日/周/月的标签占比环形图、趋势堆叠图
- 作息规律：起床/入睡时间散点、平均专注块时长
- 自定义追踪（会员）：任选标签建立追踪目标，如"每周运动 ≥ 3 次"，AI 在周报中反馈进度

## 7. 非功能需求

| 项 | 要求 |
|----|------|
| 启动速度 | 冷启动到可记录 < 1.5s（3 秒原则的前提） |
| 离线可用 | Web 阶段：在线为主，写操作乐观更新 + 失败队列重试（IndexedDB 暂存），弱网记录不丢；App 阶段：完全离线优先（schema 已预留同步字段） |
| 数据安全 | 本地优先；云同步（会员）端到端加密可选；一键导出 Markdown + JSON |
| AI 隐私 | 明示哪些数据会发送给大模型；提供"敏感胶囊"标记，标记后永不参与 AI 请求 |
| AI 供应商 | 服务端代理大模型调用（利于计费与切换供应商）；支持用户自带 API Key（极客选项，P2） |

## 8. 关键页面清单（MVP）

1. **今日页**：时间轴 + 滴答栏 + 封存入口
2. **胶囊编辑页**（半屏弹层）：标签、概括、详情、心情、时间调整
3. **封存流程页**：回放动画 → AI 复盘展示/编辑 → 封存确认
4. **档案馆页**：日历视图 + 历史时间轴查看
5. **报告页**：日复盘列表（周/月报占位"敬请期待"）
6. **我的页**：标签管理、提醒设置、日界/默认起床时间设置、数据导出、账号注销（合规必须）、会员入口
7. **onboarding**：3 屏以内。第 1 屏讲清价值主张，第 2 屏让用户当场滴答第一颗胶囊（起床/刚睡醒/正在摸鱼），第 3 屏设置提醒偏好（间隔提醒的频率与时段 + 晚间封存时间；系统通知权限延后到首次封存后的高光时刻再申请）。**用户必须在 30 秒内完成第一次记录**——首次体验即核心体验。
