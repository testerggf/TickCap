服务器/ICP 备案/大模型 key 等待人工事项未就绪，M1 以**本地优先模式**交付可用产品：数据存本设备（localStorage，数据形状与 07 §3 schema 一致，含 id/时间戳/软删预留），AI 复盘走「配置 DEEPSEEK_API_KEY 则用 AI（Next API 路由代理），否则本地降级版」——降级版本就是 08 §5 的规格内行为。账号（邮箱验证码）、独立 Hono server、云同步、Web Push 移入 M2。此决策与"本地优先"产品原则一致，不构成对文档体系的推翻。
