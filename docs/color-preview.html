TickCap 主色方案 · 感官评审

同一个「今日页」，三套配色，各配浅色/深色两种模式。别分析，凭直觉：想象你每天要打开它十几次、每晚睡前在它里面封存一天——哪一个让你最想住进去？标签色（胶囊的颜色）三套方案完全相同，你只需要感受底色气质和主色（滴答按钮、现在线、封存按钮的颜色）。

怎么选

  • 方案 A 暮光琥珀：暖纸底 + 琥珀橙。气质是"手账、黄昏、温度"，情感记录属性最强，最不像办公软件。我的推荐，理由：我们的差异化就是"有温度的记录"，视觉应该第一眼就传达这一点。
  • 方案 B 晨雾靛蓝：冷纸底 + 靛蓝。气质是"专注、理性、效率工具"，最接近 Structured/Notion 的感觉，职场人群接受度最稳，但也最容易泯然于众多效率 App。
  • 方案 C 青瓷时光：青纸底 + 青瓷绿。气质是"平静、治愈、冥想感"，接近 Headspace/苹果健康的路线，独特性不错，但绿色系在"工作记录"场景略显疏离。

    • 看的时候重点感受三处：① 深色模式舒不舒服（封存都在睡前，深色使用占比会很高）；② 主色按钮想不想按；③ 胶囊卡片挂在底色上是否清爽。选定后我把令牌写进代码，之后随时可以整体换肤——这个决策可以推翻，不用有压力。
