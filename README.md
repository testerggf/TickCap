# TickCap · 滴答胶囊

> 把每一刻装进胶囊，把每一天串成时间轴，让 AI 帮你复盘人生。

**TickCap**（Tick = 时钟滴答 / 时间刻度，Cap = Capsule 时间胶囊）是一款「时刻记录 + 时间轴 + AI 复盘」三位一体的个人记录工具。

它解决一个朴素但普遍的痛点：**日子过得很快，但回头看全是空白。** 传统日记太重（要坐下来写一大段），传统时间管理工具太冷（只有统计没有内容）。TickCap 用 3 秒一次的"滴答"记录，把一天自然串成流水账时间轴，晚上由 AI 自动生成复盘——记录几乎零成本，回顾却极有价值。

## 一句话定位

**给普通人的"人生黑匣子"：记录像发消息一样轻，复盘像有个私人教练一样深。**

## 核心循环

```
滴答记录（3秒/次） → 胶囊挂上时间轴 → 晚间封存 + AI 复盘 → 周/月/年报告 → 更想记录
```
